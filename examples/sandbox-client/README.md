# sandbox-client

Vanilla-TypeScript three.js client for the `box3d-sandbox` SpacetimeDB module. Runs locally against a dev instance; deployable to GitHub Pages for a hosted demo.

## Local setup

```sh
# 1. start a local SpacetimeDB instance
spacetime start

# 2. publish the module (from repo root)
spacetime publish box3d-sandbox \
  --module-path examples/sandbox-module

# 3. install deps and start Vite
npm install
npm run dev
```

Open `http://localhost:5173/box3d-stdb/`.

## Hosting on GitHub Pages

`.github/workflows/pages.yml` builds and deploys this client on every push that touches it. Two
one-time setup steps the workflow can't do for you:

1. **Enable Pages:** repo Settings → Pages → Source = **GitHub Actions** (the repo must be public,
   or Pages-enabled on a paid plan). Pushing the workflow alone doesn't turn Pages on.
2. **Deploy the module to Maincloud** and set the client to point at it. When the page is served
   over HTTPS it defaults to `wss://maincloud.spacetimedb.com` and the database name in
   `MAINCLOUD_DB` (top of `src/main.ts`) — set that to the name you published (names are global;
   pick a unique one). A `ws://` socket can't be opened from an HTTPS page, so a local server
   won't work for a hosted visitor.

The build is served at `https://<owner>.github.io/box3d-stdb/`. Override the target for any deploy
with query params, no rebuild:

```
https://<owner>.github.io/box3d-stdb/?server=wss://your-host&db=your-db
```

## Regenerating bindings

Run from this directory after changing the module:

```sh
spacetime generate \
  --lang typescript \
  --module-path ../sandbox-module \
  --out-dir src/module_bindings
```

## Controls

| Action | How |
|--------|-----|
| **Spawn** | click ground plane (click = <5 px / <300 ms) |
| **Shoot** | click anywhere — fires a ray from camera |
| **Launch** | click anywhere — spawns a body at camera, fires along ray |
| **Drag** (default) | press-and-hold a body: mouse slides it horizontally, **Shift** lifts/lowers (sideways still slides); release to let go — the **?** on the button shows this in-app |
| **Box / Ball** | toggle shape kind before spawning or launching |
| **Orbit** | right-drag rotate, middle-drag pan, scroll zoom |

Arena reset is an operator action, not a button: `spacetime call box3d-sandbox teardown_world '[]'`.

## Structure

```
src/
  main.ts              # all app logic — scene, connection, callbacks
  module_bindings/     # generated by spacetime generate (committed)
```

Skipped: state management library, asset pipeline, separate modules per concern.
